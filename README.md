# Student Attendance Marking System

## About the Project

The Student Attendance Marking System is a menu-driven application developed using C++. The project aims to simplify the process of maintaining student attendance records.

The system allows users to enter student details, display registered students, mark attendance, search for students using their roll numbers, calculate attendance percentages, and identify students whose attendance is below 75%.

This project demonstrates the application of Object-Oriented Programming (OOP) concepts in C++.

## Project Objectives

* To develop a student attendance management application using C++.
* To store student roll numbers and names.
* To display registered student details.
* To mark student attendance.
* To search for students using their roll numbers.
* To calculate attendance percentages.
* To identify students with attendance below 75%.
* To apply Object-Oriented Programming concepts.

## Features

* Student registration
* Display all registered students
* Attendance marking with Present/Absent status
* Student search using roll number
* Attendance percentage calculation
* Identification of students with attendance below 75%
* Input validation for supported inputs
* Menu-driven console interface
